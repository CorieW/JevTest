# Licensing intent — not an adopted license

The project specification calls for public source that developers and organizations may inspect, use, self-host, and modify without a software license fee, including for testing their own commercial applications.

It reserves the right to sell or commercially license the project, or provide it as a paid hosted or managed service, exclusively to the project's rights holder. That restriction is intended to apply to modified versions too. Third-party API and infrastructure costs remain the user's responsibility.

The rights holder has chosen to make the repository public. No license has been adopted: the source is visible, but this document grants no usage or redistribution rights. `package.json` therefore uses `UNLICENSED` and `private: true` to keep package publishing disabled. The template's MIT license has not been applied to this implementation. Intended free use and modification rights remain pending adoption of terms defining permitted internal/commercial application use, redistribution, modifications, and reserved service rights.
